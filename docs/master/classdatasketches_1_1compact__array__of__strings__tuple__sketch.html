Detailed Description

template<typename Allocator = std::allocator<array_of_strings>>
class datasketches::compact_array_of_strings_tuple_sketch< Allocator >

Extended class of compact_tuple_sketch for array of strings.

Requirements:

  • Array size must be <= 127.

UTF-8 compatibility: Serialized sketches are intended to be language and platform independent. Summary strings are stored as raw bytes without UTF-8 validation. Java decodes them with new String(bytes, StandardCharsets.UTF_8), which replaces invalid UTF-8 with U+FFFD, so use valid UTF-8 for sketches shared with Java.
